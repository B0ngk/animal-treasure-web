# 동물친구 보물찾기 웹게임 — 설계 문서 (v1 MVP)

**날짜:** 2026-06-16
**목적:** 기존 PowerPoint(VBA) 게임 "동물친구 보물찾기 / 득템공방"을 단일 HTML 웹앱으로 이식
**구현 환경:** 계획은 여기서 작성, 실제 구현은 Claude Design(claude.ai)에서 진행
**원본:** `과학_5-2-3-12_13_PPT게임_동물친구보물찾기_득템공방_PPT.pptm` (114 슬라이드, VBA 8모듈)

---

## 1. 범위

### v1 MVP 포함
- **메인 보드** + 문제카드 N개(기본 15) 랜덤 배정
- **문제은행** + 랜덤 추출(중복 없음), 사용자가 다른 문제로 교체 가능
- **모둠(팀) 점수판** — 최대 8팀, 점수 +/−/초기화
- **교사 판정형 문제** — 문제/정답/해설 표시 후 교사가 정답·오답 판정
- **콘텐츠 교체** — 앱 내 편집 + JSON 불러오기/내보내기 + localStorage 저장

### v2 이후 (이번 제외)
- 보물상자 3개 선택 연출
- 아이템(득템공방) 시스템
- 자동 턴 진행 + 가림막
- 주사위 순서 정하기

### 배포 성격 (중요)
- 학기마다 **과목·문항이 바뀌어 재배포**되는 템플릿
- 엔진(HTML/JS/CSS)은 고정, **문제 데이터(JSON)만 교체**하면 새 학기·과목용으로 배포
- 단일 HTML 파일 → USB·이메일·정적 호스팅(GitHub Pages 등) 모두 배포 가능

## 2. 데이터 구조 (엔진 ↔ 콘텐츠 분리)

```jsonc
{
  "meta": {
    "subject": "과학",
    "grade": "5학년 2학기",
    "unit": "3단원 동물친구 보물찾기",
    "version": "2026-2학기"
  },
  "settings": {
    "cardCount": 15,         // 보드 문제카드 수 (questions 수보다 많으면 중복 허용)
    "pointsPerCorrect": 10   // 정답 시 기본 점수 (교사 조정 가능)
  },
  "questions": [
    {
      "id": 1,
      "question": "광합성이 일어나는 곳은 어디인가요?",
      "answer": "잎의 엽록체",
      "explanation": "엽록체에서 빛에너지를 이용해 양분을 만듭니다."  // 선택 필드
    }
    // ... N개
  ]
}
```

- `meta` + `questions` = **교체 단위** (학기·과목 변경 시 이 JSON만 교체)
- 엔진은 `questions`에서 `cardCount`만큼 **중복 없이 랜덤 추출** → 보드 카드에 배정
  - `questions` 수가 `cardCount`보다 적으면 중복 허용하여 채움 (원본 VBA 로직과 동일)
- 문제는 교사 판정형이므로 `question/answer/explanation` 3필드로 단순 → 전 과목 동일 구조

## 3. 화면 흐름

```
[설정] → [메인 보드] ⇄ [문제] → (정답/오답 판정) → [메인 보드]
              ↑                                          ↓
       [문제 편집/가져오기 모달]            모든 카드 소진 → [결과]
```

| 화면 | 내용 |
|------|------|
| **설정** | 모둠 수(1~8)·이름 입력, 카드 수, 정답 점수, 문제셋 불러오기/내보내기 버튼, 게임 시작 |
| **메인 보드** | 좌측: 문제카드 그리드(번호 표시, 사용한 카드 비활성). 우측: **모둠 점수판 상시 표시**(B 레이아웃) |
| **문제** | 문제 텍스트 → `정답 보기` 클릭 시 정답·해설 공개 → `정답`/`오답` 버튼. `홈` 버튼으로 보드 복귀 |
| **결과** | 모든 카드 소진 시 모둠 순위·우승팀 표시 + 폭죽 효과 |

### 판정 흐름 (우측 점수판 활용)
1. 보드에서 카드 클릭 → 문제 화면 진입 (해당 카드는 '사용 중')
2. `정답 보기` → 정답·해설 공개
3. `정답` 클릭 → **우측 점수판에서 팀 선택 → 해당 팀 +pointsPerCorrect** → 보드 복귀, 카드 '사용 완료'(비활성)
4. `오답` 클릭 → 점수 변동 없이 보드 복귀, 카드 '사용 완료'
5. 점수판의 각 팀에는 수동 +/− 버튼도 있어 교사가 자유 조정 가능

## 4. 콘텐츠 소스 추상화 (서버 배포 대비)

문제 데이터 로딩을 추상화 계층으로 설계해, 서버 배포 시 URL fetch만 추가하면 되도록 함.

```js
ContentSource = {
  load()        // ① 기본 내장 데이터 → ② localStorage 순으로 로드
  import(file)  // ③ JSON 파일 불러오기 → 검증 → localStorage 저장 → 적용
  export()      // 현재 문제셋을 JSON 파일로 내보내기 (meta.version 기반 파일명)
  reset()       // 기본 내장 데이터로 초기화
  // 추후 서버 배포 시: ④ loadFromUrl(url) 만 추가하면 됨 (엔진 수정 불필요)
}
```

- **import 검증:** `questions` 배열 존재 + 각 항목에 `question`/`answer` 필드 확인. 누락 시 토스트 경고, 적용 중단.
- **서버 배포 경로:** 정적 호스팅에 올리면 동일 출처에서 `fetch('questions/과학_5-2.json')` 가능 → 학기·과목별 문제셋 URL 선택 로드로 확장.

## 5. 파일 구조 & 타이포그래피

- **단일 파일:** `동물친구보물찾기_웹게임.html` (엔진 + CSS + JS + 폰트 임베드, 외부 의존성 0)
- **폰트:** `강원교육튼튼` (원본 PPT 동일 폰트)
  - OTF(764KB) → **WOFF2 변환 후 base64 `@font-face` 임베드** (용량 ~300KB, 오프라인·전자칠판·폰트 미설치 PC 대응)
  - 본문·제목·점수판 모두 이 폰트로 통일
- **기본 문제셋:** 원본 pptm의 과학 5-2 문제를 기본 내장 → 파일 열면 즉시 플레이 가능
- **반응형:** 전자칠판(16:9 대화면) 우선, 일반 PC·태블릿에서도 레이아웃 유지

## 6. 상태 관리 (게임 진행)

```js
GameState = {
  teams: [{ name, score }],   // 1~8팀
  cards: [{ slot, questionId, used }],  // 보드 카드 N개, questionId는 랜덤 배정
  pointsPerCorrect,
  currentCardSlot,            // 문제 화면에서 다루는 카드
  phase                       // 'setup' | 'board' | 'question' | 'result'
}
```

- 게임 진행 상태는 메모리(런타임)에서 관리, 새로고침 시 초기화 (MVP 범위)
- 설정·문제셋만 localStorage 영속 (게임 중간 저장은 v2 후보)

## 7. 테스트 체크리스트

- [ ] 파일 열면 기본 문제셋으로 즉시 보드 표시·플레이 가능
- [ ] 설정에서 모둠 수 변경 → 점수판에 해당 수만큼 팀 표시
- [ ] 카드 클릭 → 문제 표시 → 정답 보기 → 정답·해설 공개
- [ ] `정답` → 팀 선택 → 점수 +pointsPerCorrect, 카드 비활성
- [ ] `오답` → 점수 변동 없이 카드 비활성
- [ ] 모든 카드 소진 → 결과 화면에 순위·우승팀
- [ ] JSON 내보내기 → 같은 파일 불러오기 → 동일 문제셋 복원
- [ ] 잘못된 JSON 불러오기 → 경고 표시, 기존 데이터 유지
- [ ] 새로고침 후에도 설정·문제셋 유지(localStorage)
- [ ] `강원교육튼튼` 폰트가 미설치 PC에서도 표시
- [ ] 전자칠판(대화면) 및 일반 PC에서 레이아웃 정상
