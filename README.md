# 동물 친구 보물 찾기 — 웹앱

초등 과학 수업용 PPT 게임 **"양송이샘의 동물 친구 보물 찾기 / 득템공방"** 을
브라우저에서 바로 실행할 수 있는 웹앱으로 옮기는 작업입니다.
원본은 PowerPoint 114 슬라이드 + VBA 매크로 약 2,700줄로 만들어져 있습니다.

## 실행 방법

`webapp/` 안의 정적 파일이 전부입니다. 로컬 서버로 열어야 폰트가 정상 적용됩니다.

```bash
cd webapp && python3 -m http.server 8000
```

그다음 브라우저에서 <http://localhost:8000> 을 엽니다.

> 파일을 더블클릭해 `file://` 로 열면 폰트 로딩이 차단될 수 있으므로
> 위와 같이 로컬 서버로 실행하세요.

## 진행 상황

| 화면 | 원본 슬라이드 | 상태 |
|------|--------------|------|
| 타이틀 (내용 확인 문제) | slide4 | ✅ 완료 |
| 설정 및 조작법 | slide9 | ✅ 완료 |
| 메인 보드 (문제카드 + 모둠 점수판) | slide10 | ✅ 완료 |
| 보물찾기 결과 · 보물상자 · 아이템 획득 | slide19~69 | ✅ 완료 |
| 문제 / 정답·해설 | slide70~ | ✅ 완료 |
| 아이템 효과 적용 | slide8 | ✅ 완료 |
| 결과 화면 (황금별 정산) · 크레딧 | — | ⬜ 예정 |

설계와 계획은 `docs/` 에 있습니다.

- `docs/specs/` — 설계 문서 (데이터 구조, 화면 흐름, 배포 전략)
- `docs/plans/` — 구현 계획

## 핵심 원칙

**1. 원본 디자인을 눈대중으로 재현하지 않는다.**
슬라이드 크기가 12192000×6858000 EMU = 정확히 1280×720 px 이므로,
PPT 의 좌표를 9525 로 나누면 웹 무대 좌표와 1:1 로 대응합니다.
모든 요소는 이 실측값으로 배치합니다.

**2. 원본 이미지·폰트를 그대로 재사용한다.**
캐릭터·보석·보물상자·주사위 등은 팀에서 직접 제작한 에셋이므로
`assets/original/` 에 추출해 두고 그대로 씁니다. 폰트도 원본과 같은
**강원교육튼튼** 을 사용합니다.

**3. 캐릭터·아이템은 한 번 만들어 고정한다.**
과목·학기가 바뀌어도 같은 에셋 파일을 참조해 일관성을 유지합니다.
바뀌는 것은 문제 데이터(JSON)뿐입니다.

## 폴더 구조

```
webapp/              실행되는 웹앱 (이것만 배포하면 됨)
  index.html         화면 + 로직 (단일 파일)
  assets/            사용 중인 이미지 + 강원교육튼튼 폰트
assets/original/     원본 PPT에서 추출한 이미지 104개
assets_test/         Higgsfield 스타일/포즈 검증 결과
docs/                설계·계획·좌표 데이터
tools/               PPT 좌표 추출 도구
_vba_all.txt         원본 VBA 매크로 전문 (포팅 참조용)
```

## 원본 PPT 좌표 확인

원본 `.pptm` 은 상용 배포물이라 저장소에 포함하지 않습니다.
포팅에 필요한 좌표는 이미 추출해 커밋해 두었습니다.

```
docs/slide-coordinates.json   # 슬라이드 114개 전체의 좌표·색상·폰트
webapp/questions.json         # 문제은행 15문항 (문제·정답·해설)
```

과목·학기가 바뀌면 `webapp/questions.json` 만 교체하면 됩니다.
원본에서 다시 뽑으려면 `python3 tools/dump_questions.py` 를 실행하세요.

원본 파일이 있는 PC에서는 아래처럼 다시 추출할 수도 있습니다.

```bash
# .pptm 을 저장소 루트에 두고 실행
python3 tools/extract_slide.py 10 --layout    # 슬라이드 10 좌표
python3 tools/dump_coordinates.py             # 전체 좌표 JSON 재생성
```

## 다른 PC에서 이어서 작업하기

```bash
git clone <이 저장소 URL>
cd edume/webapp && python3 -m http.server 8000
```

필요한 에셋·폰트·좌표가 모두 커밋되어 있어 추가 준비 없이 이어서 작업할 수 있습니다.
(`_media/`, `_slides/` 는 `.pptm` 에서 재생성되는 작업 폴더라 커밋하지 않습니다.)
